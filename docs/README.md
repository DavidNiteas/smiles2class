# smiles2class docs

**Languages:** [English](./en/index.md) · [简体中文](./zh-CN/index.md)

The docs go from first run to reference:

1. **Scope** — why the repository is code-only, and what you must provide.
2. **Start** — install and run the smallest example.
3. **Use** — data preparation, training, models, API and CLI.
4. **Check** — per-class evaluation and report fields.
5. **Why code-only** — data and model distribution boundaries.

The repository contains code only. It does not include HMDB/LIPID MAPS data or trained model weights.
